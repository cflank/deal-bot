# 比价机器人网站 · 设计规则

改页面前先读这份文件。要改规则，先改这里，再改页面。

v1（2026-11-12）：用户从三个方向（价签 / 账本 / 手写牌）里选了「价签」。

## 对象

- 是什么：盯价工具。用户列出想买的东西和心理价，降到价就推到手机。
- 给谁：站长的熟人，中文用户，人在加拿大。基本都在装了 Bark 的 iPhone 上打开。
- 页面唯一的任务：一眼看出“现在有没有值得买的”。
- 方向：货架价签。价格数字是页面上最大的东西；到价的那张变成黄色清仓签。

## 语言

- 界面中文，句子用大白话。商品标题保持商家原文（多为英文）。
- 金额一律加元，写 `$850`，不写 CAD。

## 颜色

| 名称 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| `--shelf` | `#F3F4F1` | `#141514` | 页面底色（货架条） |
| `--tag` | `#FFFFFF` | `#222422` | 价签底 |
| `--ink` | `#151515` | `#F1F2EE` | 文字、价签边框 |
| `--mute` | `#666963` | `#A2A59E` | 次要文字 |
| `--clearance` | `#FFD60A` | `#FFD60A` | **只给到价的价签**和当前标签页。黄底上的字永远是 `#151515` |
| `--drop` | `#D9261C` | `#FF5A4F` | 只给「到价」贴纸、报错和删除 |

- 黄色是全站唯一的强调色，出现就代表“到价”或“当前所在”。不拿它做装饰。
- 红色面积要小。

## 字体

- 价格数字：`"DIN Condensed", "Avenir Next Condensed", "Bahnschrift", "Arial Narrow", sans-serif`，粗体。都是系统自带字体（iPhone 上是 DIN Condensed），不下载网络字体。
- 其它文字：系统字体 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。
- 字号：价格 44 / 页面标题 22 / 商品名 17 / 正文 15 / 说明 13。行高正文 1.5。
- 价格的写法：`$` 和小数部分用小字号上标，整数部分最大（`$924.99` → 大的 924，小的 .99）。

## 版式

```
┌──────────────────────────┐
│ 比价机器人      12 分钟前 │  页头：左对齐标题，右侧更新时间
│                          │
│ iPhone Air     提醒价 $900│  商品名 + 提醒价
│ ┌──────┬───────────────┐ │
│ │ $850 │ 标题（商家原文）│ │  价签：左价格、右说明，1.5px 黑边
│ │      │ 二手 · Kijiji  │ │  到价 → 整张黄底 + 右上「到价」贴纸
│ └──────┴───────────────┘ │
│ ┌──────┬───────────────┐ │
│ │ $925 │ …             │ │
│ └──────┴───────────────┘ │
│                          │
├──────────────────────────┤
│  看板     商品     设置   │  底部标签栏，固定，黑底
└──────────────────────────┘
```

- 单栏，内容左对齐，最大宽度 560px，桌面上居中。
- 底部标签栏固定；管理员多一个「管理」。
- 圆角：价签 3px，按钮和输入框 6px。不用阴影。

## 组件

- 价签：见上。标题是链接，点了在新标签页打开商家页面。
- 按钮：主按钮黑底白字（深色模式反过来）；次按钮黑边透明底；危险操作红字。高度至少 44px。
- 表单：标签在输入框上方，说明文字在下方，13px。
- 多选（成色、数据源）：做成可点的方块标签，选中黑底。
- 空状态：一句话说明 + 一个能点的按钮。
- 报错：红字，直接说出了什么问题、怎么办。

## 文案

- 按钮写它做的事：「获取验证码」「保存商品」「发送测试推送」。
- 不卖弄，不感叹号，不写“智能”“一键”。
- 成色统一叫：全新 / 开箱 / 翻新 / 二手。

## 不做的事

- 不用渐变、阴影、卡片堆叠、图标库、emoji 当图标。
- 不做进场动画。只有操作反馈可以动（展开、保存成功）。
- 不用全大写英文小标题，不用 `·` 之外的装饰分隔，按钮文字后不加箭头。
- 不把黄色用在到价和当前标签页之外的地方。
- 不显示用户的 Bark 地址（只显示有几台手机）。

## 技术

- 纯 HTML / CSS / JS，没有构建步骤，没有第三方脚本和字体。
- 一个页面 `static/index.html`，视图用 `#/board` 这样的地址切换。
- 遵守 `prefers-color-scheme` 和 `prefers-reduced-motion`；键盘可操作，焦点可见。
