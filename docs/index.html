      推送用 Bark（iPhone）。设备 Key 存放在仓库的 Settings → Secrets → Actions → BARK_KEY，不会出现在这个公开页面里；多台手机就每行填一个。达到“最高优先级”折扣的推送会以“时效性通知”送达，专注模式下也会提醒。
